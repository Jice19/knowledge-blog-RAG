## 明文与加密

HTTP 是明文传输，报文可以被中间人窃听和篡改。HTTPS 在 HTTP 与 TCP 之间加了 TLS 层，用加密保护数据。加密分对称加密和非对称加密：非对称加密交换密钥，对称加密传输数据，兼顾安全与性能。

## 证书与身份验证

HTTPS 用数字证书验证服务器身份。证书由权威机构 CA 签发，包含公钥和域名。客户端用 CA 的根证书校验服务器证书，防止中间人伪造服务器。这就是浏览器地址栏出现小锁的含义。

## 握手过程

TLS 握手大致是：客户端发起请求，服务器返回证书，客户端验证证书后用公钥加密一个随机数，双方据此协商出对称密钥，之后的数据都用这个密钥加密传输。理解这个过程就能回答面试官关于 HTTPS 安全性的问题。
